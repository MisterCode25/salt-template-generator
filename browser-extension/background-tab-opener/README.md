# Template Generator Background Tab Opener

This unpacked Chrome/Edge extension lets Template Generator open configured link tools in inactive browser tabs.

## Install in Edge

1. Open `edge://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this folder: `browser-extension/background-tab-opener`.

## Install in Chrome

1. Open `chrome://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this folder: `browser-extension/background-tab-opener`.

The app still needs each link tool to have `Open in background tab` enabled.
